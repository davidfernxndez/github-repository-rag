# GitHub Repository RAG

Retrieval-Augmented Generation (RAG) system for asking questions about the content and structure of GitHub repositories.

## Overview

This project allows users to provide a GitHub repository and query its contents using natural language.

The system retrieves relevant information from the repository and uses it as context to generate answers.

## Features

* GitHub repository ingestion
* Document and code retrieval
* Semantic search
* LLM-based question answering

## Tech Stack

* Python
* LangChain
* Embeddings
* Vector database
* Large Language Model (LLM)
